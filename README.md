## 📌 Overview

An interactive CLI-based exploratory data analysis comparing the content libraries of **Netflix** and **Amazon Prime Video**. The script loads both catalogs from CSV files and lets you explore content distribution, rating breakdowns, and yearly release trends through visualizations.

---

## ✨ Features

| Code | Analysis | Output |
|:---:|---|---|
| `1` | **Content Distribution** | Side-by-side pie charts — Movies vs TV Shows on each platform |
| `2` | **Content Details** | Total titles, movie count, TV show count for both platforms |
| `3` | **Rating Distribution** | Top-10 content ratings bar chart comparison |
| `4` | **Yearly Release Trends** | Line chart of titles released per year (last 20 years) |

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/Kris-Zar/Netflix-Vs-Amazon-Content-Analysis.git
cd Netflix-Vs-Amazon-Content-Analysis
```

2. **Install dependencies**

```bash
pip install -r requirements.txt
```

3. **Run the analysis**

```bash
python Netflix_Vs_Amazon.py
```

4. **Enter a code (1–4)** to view the corresponding analysis
